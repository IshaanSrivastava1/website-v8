AI Market Brief Agent

Python · Claude API · Tool Use · Agent Loop · Web Search · GitHub Actions

View live tracker →

What I Built

  • A "What's going on today" section at the top of my gold arbitrage tracker, written by an AI agent instead of a template. The tracker scans every open gold-price market on Polymarket and Kalshi every 30 minutes and flags contracts priced inconsistently against each other — it shows the numbers well but couldn't explain them.
  • The agent is given three tools and decides for itself which to use and when it has enough to write: one returns the arbitrage opportunities found in the current scan, one returns the normalised contract prices from both platforms, and a third runs a web search on Anthropic's own infrastructure, so there's no second API key or news provider to manage.
  • It typically checks the market data first, and only searches the news when something in the numbers needs explaining, then writes a few paragraphs on what stands out, citing its sources — rendered as links under the brief.

How It Works

  • The loop: the model picks a tool, the code runs it, the result goes back, and it repeats until the model stops asking. That loop is the whole idea of an agent.
  • Two calls by design: the agent researches and writes prose, then a second, cheaper call reformats that prose into a headline, body, and source list for the page. Keeping the tool loop separate from the output shape keeps both simple.
  • Cost control: the workflow runs 48 times a day, and regenerating the brief every time would mostly rewrite the same paragraph. It's regenerated only when the set of detected opportunities actually changes, or when the cached one passes six hours old — taking it from 48 model calls a day to a handful.
  • Fail-open: if the model is unavailable, the previous brief is shown marked as possibly out of date, or the section removes itself. A failed brief never fails the page build — 26 unit tests cover the caching and fallback logic.

Thesis

I built this to learn how AI agents actually work, alongside a second project (the job-fit scoring agent) that does the same thing in a different shape. This one is the fuller version: a genuine tool-use loop where the model decides what to check rather than following a fixed script.

The honest limitation: the agent describes and explains, it does not advise. The page says so explicitly, and the brief is written to avoid predictions or trade recommendations.
